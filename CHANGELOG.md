## [1.0.0] - 2026-09-01

### Added

- Touchpad-only pickleball scoring optimized for the 640×360 Google Glass XE display.
- Singles and doubles setup flows with either side serving first.
- Correct doubles opening-server exception and Server 1/Server 2 side-out rules.
- Regulation games to 11 with a two-point winning margin.
- Multi-level undo, guarded reset, post-game, and exit confirmation flows.
- Offline checkpoint persistence with process, reboot, and battery-loss recovery.
- Strict checkpoint validation and a safe recovery path for damaged state.
- Public build, test, signing, and GitHub release automation.
